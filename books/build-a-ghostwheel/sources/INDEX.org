* What this is

Every fact in the book carries witness rows (=== facts ==== in each spread under =src/=), and each row
names the file it came from (=from:=) and that file's sha256 when it was read (=sha:=). This folder
holds those files, so a reader or researcher can check a row without access to the C4 tree it was read
from. Corwin's word, 2026-11-04: "OK to publish underlying materials RE C4 so there is contunity for
readers/researchers".

- *Where*: a row's =from: c4/X= is the file =sources/c4/X= here, byte for byte as it stood in C4.
- *When*: read from C4 on 2026-11-04 (the book's rows were seen on 2026-11-03 and 2026-11-04, UTC).
- *Check one yourself*: =sha256sum sources/c4/facts/drift= and compare it with the hash below and with
  the row's =sha:= line in =src/=.
