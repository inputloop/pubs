* WHAT THIS COOKS

The essay argues about numbers; this recipe is where its numbers can be *re-made* by a stranger, in the
tree, without trusting the essay. It keeps the essay's own distinction in its output, because the
distinction is the argument:

- a *CHECK* is something that must not drift. It has an expected value and it can go RED. The urgent pile
  on 2026-09-26 is 39, and two readers in two languages (awk and Python) must agree on every day of it.
- a *GAUGE* is something to be weighed. It prints what was seen on 2026-09-26 beside what is found now,
  and it never says pass or fail. The tree grows; a count that moves is news, not a fault. Asking a gauge
  a check's question is the failure the companion paper names: "a number nobody validated, wearing a
  test's authority" (=pub/papers/red-first-then-counted/=).

Four languages carry the work, on purpose (his rule of 2026-09-14: when something gets past our tests,
add coverage in a language separate from the work under test). The tool whose thresholds the sweep
reads, =bin/cl1ix=, is Python; the sweep is Perl. The probes are sh, and the one receipt that matters
most (P2) is computed twice, in awk and in Python, and must agree.

* THE GRAIN — which house number, if any (the keeper's finesse, 2026-09-26)

His reprompt, verbatim: "sometimes we really are counting and it's silly to invent a reason to stop
counting at a number because we happen to have numbers and also like to stop counting when we aren't sure
the max ... If we are setting a unknown number we might well (nearly always should when we have no
specific direction otherwise to guess) reach for the magic number when applying it. The finesse is how:
the only meaningful guide I have offered so far are the names for the magic stops on the dial: GRAIN,
GREAT, GRAND."

Four readers took that as a third take, blind to one another (=magic-number-theory/arms-2026-09-26/R3-*.md=). They agreed
on the procedure below. The ring reading is theirs, not his; his units are recorded as withheld
(=AS4CE0001/memory/as-ce-slide.md=), and his word overrides every line of it.

1. *Are you already counting?* Then use the count. Do not stop it at a house number because the maximum is
   unknown; finish it, or say plainly that you stopped and why. (=mn-grain counted N=)
2. *Setting a number nobody can count or derive?* Reach for the dial, and pick the stop by the *ring the
   number must serve*, the reading =h/ms1dg= gives its ceremony dial ("the size of the RING the ceremony is
   meant to convince"):
   - *GRAIN, 4* — a small ring; the default when nothing says otherwise. His hand-edit of 2026-09-04:
     "GRAIN: (default)4 or GREAT:9, or GRAND:17".
   - *GREAT, 9* — strangers take part, or the plan travels among several parties.
   - *GRAND, 17* — it must stand on a shelf, or hold between organizations.
   Never climb for size: a long thing for a small ring is still GRAIN.
3. *Write the name beside the number*: "9 (GREAT, from the dial)". The name is the disclosure.
4. *Left of the grain is not magic.* Below 4 the dial is plain doubling (2 a pair, 1 yourself, and the halves
   below), "rational numbers that make sense as doubling" in his words; those need no confession. The
   magic is counting *up*: 9 = 2×4+1 and 17 = 2×9−1.
5. *Staged reach counts up the stops.* When one horizon will not do (a falsifier's settlement dates),
   use the ladder: 4 GRAIN · 9 GREAT · 17 GRAND, each checkpoint for a wider ring. (=mn-grain ladder=)

Open on his word, and said here so nobody has to fish for it: the persona grid sizes a persona by length
("4 for a tiny sketch, 9 for a short work, 17 for a long one"), which step 2's "never climb for size"
would forbid; and the 17% drift budget is a share, left of the grain, where step 4 says a halving would be
the natural pick. Either ruling reshapes this section.

** mn-sweep — the threshold gauge that walks the whole curve (Perl)
A second language for the numbers =bin/cl1ix= (Python) sets. It prints where the answer is flat; it never says a threshold is good. =--prove-red= runs five planted curves and a negative control.
#+begin_src perl :tangle mn-sweep
#!/usr/bin/perl
# mn-sweep -- a GAUGE for a threshold laid over a count. It walks the WHOLE curve (every
#   threshold from 1 to the largest count), not only the dial's stops, and says where the answer
#   is flat. It prints counts; it never says whether a threshold is good. Written in Perl on
#   purpose: the tool whose thresholds it is meant to sweep (bin/cl1ix) is Python, and the
#   probes beside it are sh/awk/Python -- a second language reads the same numbers.
#
# Copyright (C) 2026 Corwin Brust <corwin@bru.st>.  Authored by Mentat (for Corwin).
# SPDX-License-Identifier: GPL-3.0-or-later
#
# INPUT (stdin or FILE): one item per line, TAB separated:
#     ITEM  COUNT            -- an item passes threshold t when COUNT >= t
#     ITEM  COUNT  SPREAD    -- paired form (cl1ix's turns: uses >= t AND hunks >= t)
#   Lines starting with # are skipped. COUNT and SPREAD are whole numbers >= 0.
# OUTPUT (words, one line each):
#     the dial's stops, named: 1 yourself · 2 a pair · 4 GRAIN · 9 GREAT · 17 GRAND · 26 the alphabet
#     for each: items at or above it, and the FLAT RUN it sits in (the thresholds either side that
#     give the same answer). Width 1 = the stop sits on a slope; a wide run = a plateau.
#     then the widest flat run anywhere on the curve (so a plateau BETWEEN stops is seen).
#   --curve   also print every run of the curve (from..to -> items).
# A flat run is a count, not a verdict: whether a plateau is wide enough is the reader's call.
#
# usage: mn-sweep [--curve] [FILE]     mn-sweep --prove-red     exit 0 ok / 1 prove-red failed / 2 usage
use strict; use warnings;

my @STOPS = ([1,'yourself'],[2,'a pair'],[4,'GRAIN'],[9,'GREAT'],[17,'GRAND'],[26,'the alphabet']);

sub load {
    my ($fh) = @_; my @it;
    while (my $l = <$fh>) {
        chomp $l; next if $l =~ /^\s*(#|$)/;
        my @c = split /\t/, $l;
        die "mn-sweep: line $.: want ITEM<TAB>COUNT[<TAB>SPREAD]\n" if @c < 2 || $c[1] !~ /^\d+$/ || (@c > 2 && $c[2] !~ /^\d+$/);
        push @it, [$c[1], (@c > 2 ? $c[2] : undef)];
    }
    return \@it;
}
sub keyof {                            # an item passes t iff its key >= t; paired form: key = min(COUNT, SPREAD)
    my ($x) = @_; return (defined $x->[1] && $x->[1] < $x->[0]) ? $x->[1] : $x->[0];
}
sub curve {                            # runs [from, to, items] over t = 1 .. max+1, by a histogram (O(items + max))
    my ($it) = @_; my ($max, %h) = (0);
    for (@$it) { my $k = keyof($_); $h{$k}++; $max = $_->[0] if $_->[0] > $max }
    my @at; my $n = 0;                 # $at[t] = items whose key >= t (suffix sum)
    for (my $t = $max + 1; $t >= 1; $t--) { $n += ($h{$t} // 0); $at[$t] = $n }
    my @runs; my $prev;
    for my $t (1 .. ($max + 1)) {
        if (defined $prev && $at[$t] == $prev->[2]) { $prev->[1] = $t } else { $prev = [$t, $t, $at[$t]]; push @runs, $prev }
    }
    return (\@runs, $max);
}
sub report {
    my ($it, $want_curve) = @_; my @out;
    my ($runs, $max) = curve($it);
    push @out, sprintf('items %d; largest count %d; the curve has %d flat run(s) from 1 to %d', scalar @$it, $max, scalar @$runs, $max + 1);
    for my $s (@STOPS) {
        my ($t, $name) = @$s;
        if ($t > $max + 1) { push @out, sprintf('stop %2d (%s): above every count -- nothing passes', $t, $name); next }
        my ($r) = grep { $_->[0] <= $t && $t <= $_->[1] } @$runs;
        push @out, sprintf('stop %2d (%s): %d at or above; flat from %d to %d (width %d)', $t, $name, $r->[2], $r->[0], $r->[1], $r->[1] - $r->[0] + 1);
    }
    my ($w) = sort { ($b->[1]-$b->[0]) <=> ($a->[1]-$a->[0]) || $a->[0] <=> $b->[0] } grep { $_->[2] > 0 } @$runs;
    push @out, $w ? sprintf('widest flat run with anything passing: %d to %d (width %d), %d at or above', $w->[0], $w->[1], $w->[1]-$w->[0]+1, $w->[2])
                  : 'widest flat run: none (nothing passes any threshold)';
    if ($want_curve) { push @out, sprintf('  run %d..%d -> %d', @$_) for @$runs }
    return join("\n", @out) . "\n";
}
sub prove_red {
    my ($ok, $bad) = (0, 0);
    my $case = sub { my ($name, $good) = @_; if ($good) { $ok++; print "  ok    $name\n" } else { $bad++; print "  RED   $name\n" } };
    # 1. a pure slope: one item at every count 1..100 -> every stop has width 1
    my @slope = map { [$_, undef] } 1..100;
    my $r = report(\@slope, 0);
    $case->('slope: GREAT sits on a slope (width 1)', $r =~ /stop  9 \(GREAT\): \d+ at or above; flat from 9 to 9 \(width 1\)/);
    $case->('slope: GRAND sits on a slope (width 1)', $r =~ /stop 17 \(GRAND\): \d+ at or above; flat from 17 to 17 \(width 1\)/);
    # 2. a plateau across the stops: items at 2 and at 30 only -> 3..30 is flat
    my @plat = ((map { [2, undef] } 1..5), (map { [30, undef] } 1..5));
    $r = report(\@plat, 0);
    $case->('plateau: GREAT sits on a plateau 3..30', $r =~ /stop  9 \(GREAT\): 5 at or above; flat from 3 to 30 \(width 28\)/);
    # 3. a plateau BETWEEN stops (11..16) must still be seen: items at 1..10 and 16..100
    my @between = map { [$_, undef] } (1..10, 16..100);
    $r = report(\@between, 1);
    $case->('between: the run 11..16 is on the curve', $r =~ /run 11\.\.16 -> 85/);
    $case->('between: it is the widest run', $r =~ /widest flat run with anything passing: 11 to 16 \(width 6\)/);
    # 4. the paired form: SPREAD must also reach t
    my @pair = ([20, 3], [20, 20]);
    $r = report(\@pair, 0);
    $case->('paired: at GREAT only the item with spread 20 passes', $r =~ /stop  9 \(GREAT\): 1 at or above/);
    # 5. negative control on the prover itself: a doctored expectation must NOT match
    $r = report(\@slope, 0);
    $case->('control: a wrong expectation does not match', $r !~ /stop  9 \(GREAT\): \d+ at or above; flat from 3 to 30/);
    printf "-- prove-red: %d ok, %d red --\n", $ok, $bad;
    return $bad == 0;
}

my $curve = 0; my $file;
while (@ARGV) {
    my $a = shift @ARGV;
    if ($a eq '--prove-red') { exit(prove_red() ? 0 : 1) }
    elsif ($a eq '--curve') { $curve = 1 }
    elsif ($a eq '-h' || $a eq '--help') { print "usage: mn-sweep [--curve] [FILE] | --prove-red\n"; exit 0 }
    elsif ($a =~ /^-/) { print STDERR "mn-sweep: unknown option $a\n"; exit 2 }
    else { $file = $a }
}
my $fh;
if (defined $file) { open($fh, '<', $file) or do { print STDERR "mn-sweep: cannot read $file\n"; exit 2 } } else { $fh = \*STDIN }
my $it = load($fh);
print report($it, $curve);
exit 0;
#+end_src

** c4check — run the CHECK fragments (EXECUTES cmd:/mustnot:)
Carried verbatim from =derive/emacs-recipe/RECIPE.org= (sha256 =62b22b4b…=), so this kit stands alone. Its security note stands too: it runs what the file declares.
#+begin_src sh :tangle c4check
#!/bin/sh
# c4check -- parse C4 CHECK fragments from a literate .org (or a bare .c4) and RUN them.
# CHECKs are the "shouldn't-be-props" layer: not data ON the thing, but assertions that
# ride WITH it -- completeness, invariants, and NEGATIVE controls (a thing that must NOT
# be true). A lifter can't quietly forget a grabble, and a tool can't ship a lie unnoticed.
#
# Copyright 2026 Corwin Brust <corwin@bru.st>
# GPL-3.0-or-later. This file is not part of GNU Emacs.
#
# !! SECURITY -- READ THIS. c4check EXECUTES the cmd:/mustnot: shell it reads from SOURCE.
# !! It is NOT a safety gate for an UNTRUSTED file: running it on a hostile SOURCE runs
# !! that file's commands as you. Use it to verify a kit you already trust (yours, or one
# !! whose author you trust). For an unknown kit, READ it before you run this. The
# !! files:/completeness checks are the only ones that never execute anything.
#
# markup (inside an org  #+begin_src c4check ... #+end_src  block, or a bare .c4 file):
#   CHECK <id> | <what it asserts>
#     files:   a b c        # PASS iff every file present (completeness; NEVER executes)
#     cmd:     <shell>       # PASS iff exit 0                          (invariant; EXECUTES)
#     mustnot: <shell>       # PASS iff exit==1 (ran, found nothing)    (neg control; EXECUTES)
#     else:    <why>         # printed on every FAIL (so a stranger knows what to do)
#   NOTE mustnot trusts exit==1 as "clean"; a predicate that exits 1 for an unrelated
#        reason (e.g. `false`) is a false pass -- prefer grep/test-style predicates.
#
# Dial (C4_CARD_DIAL, default 1) sets verbosity, never the verdict:
#   >=1 PASS/FAIL line + the reason on FAIL + summary · >=4 also the test that ran
# Each check runs EXACTLY ONCE. usage: c4check SOURCE [DIR]  exit: 0 all pass / 1 any fail / 2 error
set -eu
# opportunistic C4 back-check (hooks-to-knowledge): confirm the doc beside us still
# carries the C4 this tool was built against. Absent c4mark -> skipped (a lifted-alone
# tool just does its job). Output to stderr so the render stays clean.
_c4d=$(dirname "$0"); [ -x "$_c4d/c4mark" ] && "$_c4d/c4mark" check "$_c4d" || true
set -f   # no pathname expansion: `files: *` must never vacuously pass
src=${1:?usage: c4check SOURCE [DIR]}; dir=${2:-.}
[ -f "$src" ] || { printf 'c4check: no such file: %s\n' "$src" >&2; exit 2; }
dial=${C4_CARD_DIAL:-1}; US=$(printf '\037')

tmp=$(mktemp); res=$(mktemp); trap 'rm -f "$tmp" "$res"' EXIT
awk -v US="$US" '
 function flush(){ if(id!=""){ printf "%s%s%s%s%s%s%s%s%s\n", id,US,type,US,test,US,els,US,desc } id="";type="";test="";els="";desc="" }
 /^[ \t]*#\+begin_src[ \t]+c4check/ {next}
 /^[ \t]*#\+end_src/ {next}
 /^CHECK / { flush(); l=substr($0,7); n=index(l,"|"); id=l; desc=""; if(n>0){id=substr(l,1,n-1); desc=substr(l,n+1)} gsub(/^ +| +$/,"",id); gsub(/^ +| +$/,"",desc); next }
 /^[ \t]+files:/   { type="files";   test=substr($0,index($0,":")+1); gsub(/^ +| +$/,"",test); next }
 /^[ \t]+cmd:/     { type="cmd";     test=substr($0,index($0,":")+1); gsub(/^ +/,"",test); next }
 /^[ \t]+mustnot:/ { type="mustnot"; test=substr($0,index($0,":")+1); gsub(/^ +/,"",test); next }
 /^[ \t]+else:/    { els=substr($0,index($0,":")+1); gsub(/^ +| +$/,"",els); next }
 END{ flush() }
' "$src" > "$tmp"
[ -s "$tmp" ] || { printf 'c4check: no CHECK fragments in %s\n' "$src" >&2; exit 2; }

while IFS="$US" read -r id type test els desc; do
  [ -n "$id" ] || continue
  ok=1
  case $type in
    files)   for f in $test; do [ -e "$dir/$f" ] || ok=0; done ;;
    cmd)     ( cd "$dir" && eval "$test" ) >/dev/null 2>&1 || ok=0 ;;
    mustnot) c=0; ( cd "$dir" && eval "$test" ) >/dev/null 2>&1 || c=$?; [ "$c" = 1 ] || ok=0 ;;
    *)       ok=0 ;;
  esac
  if [ "$ok" = 1 ]; then mark=PASS; else mark=FAIL; fi
  printf '%s\n' "$mark" >> "$res"
  printf '%-4s %-22s %s\n' "$mark" "$id" "$desc"
  [ "$dial" -ge 4 ] && printf '       (%s: %s)\n' "$type" "$test" || true
  { [ "$ok" = 0 ] && [ -n "$els" ]; } && printf '       -> %s\n' "$els" || true
done < "$tmp"

p=$(grep -c PASS "$res" 2>/dev/null || true); f=$(grep -c FAIL "$res" 2>/dev/null || true)
printf -- '-- %s checks, %s pass, %s fail --\n' "$((p+f))" "$p" "$f"
[ "${f:-0}" = 0 ]
#+end_src
