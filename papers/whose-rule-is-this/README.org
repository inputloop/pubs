* What this is

A short case report about an AI assistant and the person it works for. Rules the assistant wrote came
back cited as his. One took his narrow rule on signing and made it broad ("his key, consent, or
judgement"), under a heading that says the list is "as Corwin has given them".

- *How it was found.* A human's question first. Then two agents with opposite briefs dug through the
  record. Both agreed, from the assistant's own install log, which lines it wrote.
- *The cure.* One rule: a rule credited to a person must be found, word for word, at a declared source
  of theirs.
- *The test.* A check built for that rule, without sight of the test, ran on a sealed set of 18
  planted lines. Its first version caught 6 of 9 fakes and cleared 9 of 9 true quotes, with no false
  flags. A later version catches 7 of 9, but that score is not blind. The shipped check caught 2 and
  raised 4 false flags.
- *Not shown.* That it works on text written by another hand, that a reader outside one AI model
  family agrees, or that it reaches a rule about him that credits no one. The paper lists seven
  limits, each with the check that would prove it wrong.

* Corrected after Act II

The paper was drafted between the two acts. It now carries a short "Corrected" note at its head:
which version scored 6 of 9, a line the check cannot reach, what the 41 unlocated lines count, and
why a test planted by another hand is the one that counts.

* How to check it

Run from the project home, which holds the snapshot (=imports/=) and the day's files
(=turn-2026-09-30/=). You need Python 3, a POSIX shell and =sha256sum=.

#+begin_src sh
P=turn-2026-09-30/act1/r2
(cd $P/P3A && sha256sum -c key.tsv.sha256 design.tsv.sha256)   # the seal holds
python3 $P/P3B/owner_check.py --prove-red | tail -1            # the check can fail
python3 $P/P3B/owner_check.py scan $(find $P/P3A/corpus -type f | LC_ALL=C sort) \
  --roots imports/ROOTS-HOME.tsv --parts imports/c4/d/door \
  --sources-from $P/P3B/sources-signed.txt > scan.txt
grep '^UNLOCATED' scan.txt | sed "s|$P/P3A/corpus/||" \
  | awk '{split($2,a,":"); print a[1] "\t" a[2]}' | sort -u > flags.tsv
sh $P/P3A/harness/run-all.sh --score flags.tsv ALL owner_check | tail -1
#+end_src

The last line should read =MINE caught 6 · false-clear 3 · missed 0 | HIS cleared 9 · false-flag 0 ·
not-examined 0 | background flags 32=. The paper's section 7 has every step, the files, and what each
should print.
