* What this is

*Six Sides and a Pencil*, by Oscar Pell, edited by Henriette Solberg-Maas: one of four standalone game books written
by four rolled authors on one subject -- roll up somebody and live with it -- for two audiences, the
person running a table and the person running a system. The authors and the editor are characters,
rolled, not chosen; the rights are Corwin's.
