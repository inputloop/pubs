* What this is

The publication shelf for persona: the characters, places and person-models that books and programs
are written with. A persona ships separately from the book it appears in and from the program that
reads it. The same sheet serves both, and neither carries it inside. (The Google Drive arc
=ComputerPeople/persona/= is a different thing: a complete offsite store, not a publication.)

Each item is its own folder: the sheet, its README, its COPYING, and =.c4/PROVENANCE.tsv= (where each
file came from, and its hash when it was lifted). =pb2ps= lands them and =pb1ck= checks them.

* Also on this shelf, minted for each build

- =TERMS-OF-SERVICE.md= and =PRIVACY.md=: vibrobeast's Terms and Privacy Policy, minted by
  =bin/tp2mt= during =make dist= for that build and no other. Every sentence about what the servers do
  is checked against their source first. Every filter is named, and one that isn't named doesn't exist.
- =corwin/=: the contributing personality, the person whose defaults these terms are.

* What is not here, and why (said, not silently left out)

- *gw7* is now *gh7*, at his word (2026-09-25): gw7 is the node on the wheel, gh7 the host persona.
  The first landing is kept at =.c4/retired/gw7-2026-09-25/=. His machines may be named (=../.c4/hosts=);
  =pb1ck= shows each one as HOST, and paths are still what it catches.
- *bryant*: a model of a real person, so the shelf's own consent rule applies (a line in
  =.c4/consent=, recording how the word came and which version it covers; see RECIPE.org, CREDITS
  AND HOLDS). =pb2ps= refuses it by name until then.
- *kelsey-mtb-stub*, *bryant-mtb-stub*: seeds that their people haven't filled yet.
- Where a copy writes a machine path as =<F>:\...=, =<home>= or =<mnt>/=, it says so in its README and
  PROVENANCE, and the master keeps the real path (=pb2ps --scrub=). Names are never rewritten.
